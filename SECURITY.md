# Security

Do not publish credentials, browser captures, personal career documents, or user databases in commits, issues, pull requests, or workflow logs. Supply credentials through private environment configuration and user facts through authenticated runtime input.

Report security issues privately to the repository owner before opening a public issue. When private vulnerability reporting is enabled, use the repository’s Security tab to report a vulnerability.

The gateway requires authenticated access and production configuration; making the source public does not grant access to deployed services.
