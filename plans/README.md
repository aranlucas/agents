## Direction suggestions

- **Archive/restore for saved grocery resources (plan 001, shipped).** This is the
  ROADMAP's "Reusable results" journey: saved grocery results whose edits
  survive, with explicit approval before changes. The schema already
  anticipated archiving. Downside: archived rows are kept, not erased. If
  users need data erasure, hard delete must also remove artifact snapshots.
- **User-controlled conversation deletion (plan 004, spike).** Threads can be
  listed but not deleted. CopilotKit marks thread mutations as Intelligence-only,
  and a code comment records the decision to defer them. Changing that is the
  maintainer's call. It crosses four stores (ADK sessions, artifacts,
  active-run rows, pending tools).
- **Work-budget telemetry (ROADMAP item 1), not planned.** The provider adapter
  already separates provider errors and timeouts (`internal/providers/openai/model.go`),
  but no usage totals reach the AG-UI stream. A spike should confirm what usage
  metadata ADK's `LLMResponse.UsageMetadata` carries from each provider before
  any budget UI is designed. Coarse effort: L.

## Why plan 001 was chosen to ship

The brief asked for the highest-leverage plan that is a user-facing feature
grounded in repo evidence, or a substantial correctness/security fix, and that
the repo's own tests can fully verify. Plan 001 qualifies:

- It closes a visible gap (saved resources can never be removed) that the
  schema and `UpdateList` were already built to support.
- It needs no migration and no new HTTP route.
- The repo's in-memory SQLite tests verify it end to end.

Plan 002 is a real but narrow race. Plan 003 is a small contract fix. Plan 004
needs a maintainer decision first.

## Findings considered and rejected

- "Thread already running" answered with HTTP 500 (`internal/agui/handler.go`): it mirrors CopilotKit's runtime response for an occupied thread, so changing it would break the client contract.
- Public anonymous thread state readable by anyone who knows the thread id (`effectiveUserID` → `anon:<thread>`): by design, and no production registry entry sets `Public`.
- CORS reflects any origin when `*` is configured (`internal/auth/middleware.go`): auth is bearer-token, not cookie, so reflection grants no ambient credentials. Documented in the function comment.
- `GET /threads` loading full sessions: ADK's `database` `List` does not load events (`session/database/service.go` `List`), so the cost is bounded.
- One SQLite connection (`SetMaxOpenConns(1)`) with 500 ms stop polling and 250 ms replay polling: a deliberate choice (`internal/storage/db.go` comment); query cost is small at current scale.
- Provider fallback dropping buffered reasoning when a provider returns only thoughts (`internal/providers/openai/model.go` `runProvider`): intentional, so a fallback never mixes models.
- Items fixed in, or rejected by, `docs/reliability-audit.md` (page-transport idle connections, BigQuery dataset guard, preferred-store cascade, pending-tool batch atomicity, duplicate run IDs, DNS rebinding) were not re-audited.
